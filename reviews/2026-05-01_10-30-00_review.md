## 🐛 2. Bugs & Logic Errors

*Focus: Edge cases, Null-Reference risks, race conditions, off-by-one errors, infinite loops, incorrect async/await usage.*

**Issues Found:**
* **Missing CancellationToken in Interfaces:** Several methods in `IUserService` (e.g., `GetUserDetailsAsync`, `DeactivateUserAsync`) lack `CancellationToken` parameters, even though the underlying Gateway and HttpClient support them. This prevents the UI from cancelling long-running requests.
* **Direct HttpResponseMessage handling in Service:** `UserService.CreateUserAsync` handles `HttpResponseMessage` and `ReadFromJsonAsync` directly. This logic should ideally reside in the Gateway layer to maintain a clean separation of concerns and consistent error handling.

**Recommended Fixes:**
* Update `IUserService` and its implementation to include `CancellationToken token = default` for all async methods.
* Refactor `UserService.CreateUserAsync` to use a more structured return type from `IMatrixGateway.UpdateUserAsync` (e.g., returning the deserialized user object or a specialized result).
