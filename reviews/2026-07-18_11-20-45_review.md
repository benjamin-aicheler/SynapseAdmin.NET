    If Data Protection XML files on disk become corrupted or malformed (e.g., due to incomplete writes, system shutdown, or disk space issues), this dereference will trigger a generic `NullReferenceException` instead of a predictable cryptographic/format exception, potentially bubbling up and causing startup crashes.

**Recommended Fixes:**
* **Add Null Checks to XML Element Retrieval:**
  Ensure elements exist before reading `.Value` and throw a structured `CryptographicException` if the XML is malformed:

## 🐛 2. Bugs & Logic Errors

*Focus: Edge cases, Null-Reference risks, race conditions, off-by-one errors, infinite loops, incorrect async/await usage.*

**Issues Found:**
* **Ignored CancellationToken in HTTP DELETE Calls (`SynapseCompatibleAdminGateway.cs`):**
  Several raw API deletion methods accept a `cancellationToken` parameter but do not pass it down to `ClientHttpClient.DeleteAsync` or other HTTP methods, preventing active requests from being aborted on page navigation or user-cancels:
  * **Line 263 (`DeleteEventReportAsync`):** Calls `_client.DeleteAsync(url)` instead of `_client.DeleteAsync(url, cancellationToken)`.
  * **Line 294 (`DeleteRegistrationTokenAsync`):** Calls `_client.DeleteAsync(url)` instead of `_client.DeleteAsync(url, cancellationToken)`.
  * **Line 337 (`DeleteMediaAsync`):** Calls `_client.DeleteAsync(url)` instead of `_client.DeleteAsync(url, cancellationToken)`.
  * **Line 169 (`DeleteRoomAsync`):** Calls `DeleteAsJsonAsync(url, request)` but fails to pass `cancellationToken`.
* **Ignored CancellationToken in Standard CS Base Methods (`MatrixGatewayBase.cs`):**
  * Several standard client-server endpoint mappings (e.g., `GetRoomDirectoryVisibilityAsync`, `SetRoomDirectoryVisibilityAsync`, `PutRoomAliasAsync`, `DeleteRoomAliasAsync`, `GetLocalRoomAliasesAsync`) accept `cancellationToken` but omit passing them to the underlying SDK calls on `Homeserver`. *(Note: This is only a bug if the corresponding LibMatrix SDK overloads support cancellation tokens).*

**Recommended Fixes:**
* **Pass Cancellation Tokens in Gateway Deletion Endpoints:**
  Update the async HTTP calls to forward the `cancellationToken`. For example:
  ```csharp
  public override async Task DeleteEventReportAsync(string reportId, CancellationToken cancellationToken = default)
  {
      var url = $"/_synapse/admin/v1/event_reports/{reportId.UrlEncode()}";
      var resp = await Homeserver.ClientHttpClient.DeleteAsync(url, cancellationToken);
      resp.EnsureSuccessStatusCode();
  }
  ```
