## 🐛 2. Bugs & Logic Errors

*Focus: Edge cases, Null-Reference risks, race conditions, off-by-one errors, infinite loops, incorrect async/await usage.*

**Issues Found:**
* `MediaController.Avatar` and `Preview`: Both default to `image/jpeg`. If the actual media is a PNG or GIF, some browsers might struggle if the content-type header strictly says JPEG, although modern browsers are forgiving.
* `RoomMessagesViewModel` (implied): `DateTimeOffset.FromUnixTimeMilliseconds(m.OriginServerTs).DateTime` converts to local time. It's safer to use `.UtcDateTime` or preserve the `DateTimeOffset` to avoid server-side timezone ambiguity.
* `AuthController.SignIn`: Only sets `ClaimTypes.NameIdentifier`, `Homeserver`, and `AccessToken`. `MatrixAuthenticationStateProvider.GetAuthenticationStateAsync` also includes `ClaimTypes.Name`. This inconsistency might lead to `User.Identity.Name` being null in standard controllers.

**Recommended Fixes:**
* In `MediaController`, consider getting the actual MIME type from the Matrix media metadata before serving the file, or use `application/octet-stream` if unknown.
* Update `AuthController.SignIn` to also include the `ClaimTypes.Name` claim.
